
# 🤖 Supervised Classification Modeling & Hyperparameter Tuning

A complete machine learning workflow for **supervised classification**, including multiple model architectures, hyperparameter optimization, stratified cross-validation, performance evaluation, ROC-AUC analysis, confusion matrices, and automated **Champion Model** selection.

---

## 📌 Project Overview

The objective of this project is to build and compare multiple supervised machine learning models on a preprocessed dataset.

The project follows a reproducible machine learning workflow:

```text
Preprocessed Dataset
        ↓
Train/Test Split
        ↓
Stratified K-Fold Cross-Validation
        ↓
Multiple ML Models
        ↓
Hyperparameter Optimization
        ↓
Model Evaluation
        ↓
Model Comparison
        ↓
Champion Model Selection
        ↓
Model Serialization
```

The final model is saved as a `.joblib` file so it can be reused for future predictions without retraining.

## ⚙️ Hyperparameter Optimization

Hyperparameters are optimized using:

```text
GridSearchCV
```

The optimization process uses:

```text
5-Fold Stratified Cross-Validation
```

The primary optimization metric is:

```text
ROC-AUC
```

Example:

```python
GridSearchCV(
    estimator=model,
    param_grid=parameters,
    scoring="roc_auc",
    cv=StratifiedKFold(
        n_splits=5,
        shuffle=True,
        random_state=42
    ),
    n_jobs=-1
)
```

This allows the model to be evaluated across multiple parameter combinations while preserving class proportions in each fold.

## 📊 Evaluation Metrics

The models are evaluated using several metrics.

### Accuracy

Measures the percentage of correctly classified observations.

```text
Accuracy = Correct Predictions / Total Predictions
```

### Precision

Measures how many predicted positive observations were actually positive.

```text
Precision = TP / (TP + FP)
```

### Recall

Measures how many actual positive observations were correctly identified.

```text
Recall = TP / (TP + FN)
```

### F1-Score

The harmonic mean of Precision and Recall.

```text
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

### ROC-AUC

Measures how effectively the model distinguishes between the positive and negative classes across different classification thresholds.

Higher ROC-AUC generally indicates better ranking/discrimination performance.

## 🏆 Champion Model

The Champion Model is selected based primarily on the highest **ROC-AUC** score on the evaluation set, while also considering Precision, Recall, and F1-Score.

The selected model is saved as:

```text
models/champion_model.joblib
```

The model can then be loaded using:

```python

    "models/champion_model.joblib"
```

## 🔄 Complete Workflow

### Step 1 — Load Data

The project loads the preprocessed dataset:

```python
df = pd.read_csv(
```

## ⚠️ Important Data Leakage Considerations

Data leakage can cause unrealistically high model performance.

To reduce leakage risk:

* The test set is kept separate from model tuning.
* Stratified splitting is used.
* Hyperparameter tuning is performed using cross-validation.
* Scaling is performed inside pipelines for models that require it.
* The test set is not used to select hyperparameters.
* The final model is evaluated only after the tuning process.

The Champion Model is selected using the following approach:

```text
Primary Metric

Compare Precision
      ↓
```
